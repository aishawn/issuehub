工作台能做什么

三个入口，覆盖日常协作

总览

查看问题状态、最近更新和快捷操作。点击统计卡片可进入对应问题列表。

问题

按状态、项目和工作类型查找；详情里可编辑、删除或标记已解决。已解决的问题可在问题页用「已解决」筛选查看。

管理功能

管理员（TEAMAI_ADMIN_USERS）可使用知识审核遗留队列、GitLab 同步重试和用户管理。

怎么开始使用

选择顺手的入口

Web 工作台

1输入用户名首次进入时设置，浏览器会记住
2新建记录选择问题或随手记，填写项目和类型
3搜索与处理打开详情，更新内容或添加文件

AI 助手 / CLI

命令行示例
# 配置常用用户名与 Issue Hub 地址
$env:TEAMAI_USER="alice"
$env:TEAMAI_API="http://10.110.66.11:8787"

python teamai_cli.py note "记录内容" `
  --project demo --work-type 工作日常 `
  --visibility private
# 保存后 stderr 会提示 Issue Hub 查看地址与 #record=… 深链

python teamai_cli.py notes list --project demo
python teamai_cli.py notes get 12
python teamai_cli.py notes update 12 --title "新标题"
python teamai_cli.py notes delete 12

python teamai_cli.py issue "部署失败：镜像拉取超时" --project demo --work-type 模型部署
python teamai_cli.py issues update 12 --title "新标题" --content "更新后的正文"
python teamai_cli.py issues get 12

也可以让 AI 助手帮你安装

一次安装到用户目录，之后每个项目都能复用

Claude Code · TeamAI Capture

复制安装指令，粘贴到 Claude Code

Claude Code 会安装随手记 Skill、合并配置 TeamAI MCP，并告诉你如何触发。服务地址或密钥不明确时，它会先询问，不会猜测。

Skill 安装到个人配置中，不需要每个项目重复安装。MCP 连接仍需能访问公司的 TeamAI 服务。
